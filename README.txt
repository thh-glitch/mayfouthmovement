最後的教學重點
1. 成功與否必須對照「外爭主權，內除國賊」的目標。
2. 外爭主權：未能即時收回德國原有山東權益；卻透過拒簽和約，拒絕接受有損主權的安排，表明維護主權立場，部分達標。
3. 內除國賊：北洋政府仍由軍閥控制，統治問題未根本改變；卻免去曹汝霖、陸宗輿、章宗祥，部分達成懲辦被指親日官員的要求。
4. 學生完成兩條選擇鏈後，生成「雖然……卻……」句子，點選六張句子卡排成段落。
5. 可較重視成果或局限，兩種結論都須交代兩項目標的成果與未達成部分。
6. 排序容許外爭／內除兩組互換，但「雖然」須接同一目標的「卻」，評價標準在前、結論在後。

史實界線
山東問題指德國原有租借地、鐵路等權益，不等於割讓整個山東省。
拒簽不等於即時收回；個別官員免職不等於結束軍閥統治。
「內除國賊」的直接要求是懲辦相關官員，軍閥仍掌權說明整體政治局限。
新文化早於五四，兩者互相推動；女性地位和思想傳播保留不同群體、教育及接觸刊物的條件。
除口號外，內容為教材改寫及教學摘要；學生角色為教學重構，非史料原文。
舊版瀏覽器作答不被覆寫，有舊版文字作答可在學習紀錄內回看。
